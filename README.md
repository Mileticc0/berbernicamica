# Berber Mića — web sajt

Statička, samostalna verzija sajta za berbernicu "Berber Mića". Svaka HTML stranica je potpuno samostalna (slike, fontovi i skripte su ugrađeni), pa radi i offline i na bilo kom statičkom hostingu.

## Stranice
- `index.html` — početna (hero, o nama, usluge i cenovnik, utisci, zakazivanje, kontakt)
- `utisci.html` — svi utisci klijenata
- `zakazivanje.html` — zakazivanje termina (kalendar → vreme → usluga → podaci)

Sve stranice imaju SR/EN prekidač jezika.

## Objava na GitHub Pages
1. Napravi novi repozitorijum na GitHub-u.
2. Ubaci sve fajlove iz ove fascikle u koren repozitorijuma (ili u `docs/`).
3. Settings → Pages → Source: `main` branch, `/root` (ili `/docs`).
4. Sajt će biti dostupan na `https://<korisnik>.github.io/<repo>/`.

Početna stranica se automatski učitava kao `index.html`.
